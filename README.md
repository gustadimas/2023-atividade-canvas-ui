# Atividade de Canvas (UI)

Isso é de mai/2023 a jun/2023, da época da faculdade. Coloquei no GitHub em 2026 como registro e deixei como estava.

Atividade sobre interface com Canvas. Tem o menu, uma tela pra escolher o jogo, um scroll view com personagens e uma tela de login e registro, onde testei `try/catch` pra tratar erro.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.15f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
